# @typed-clickhouse/cli

[![npm](https://img.shields.io/npm/v/@typed-clickhouse/cli.svg)](https://www.npmjs.com/package/@typed-clickhouse/cli)
[![MIT license](https://img.shields.io/badge/license-MIT-yellow.svg)](https://github.com/bayoudhi/typed-clickhouse/blob/main/LICENSE)

npm wrapper that installs and runs the `typed-clickhouse` CLI binary — a type-safe,
code-first migration and query tool for ClickHouse. See the
[repository README](https://github.com/bayoudhi/typed-clickhouse#readme)
for what the tool does.

This package is derived from [514-labs/moosestack](https://github.com/514-labs/moosestack),
MIT licensed. See [`NOTICE`](https://github.com/bayoudhi/typed-clickhouse/blob/main/NOTICE)
for attribution.
